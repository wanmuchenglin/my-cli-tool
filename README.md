# my-cli-tool

一个基于 Node.js 的命令行工具（CLI）脚手架。

## 特性

- 简洁的命令行入口
- 可扩展的命令模块结构
- 基础测试目录

## 安装

```bash
npm install
```

## 使用

```bash
node bin/cli.js
```

## 目录结构

```
my-cli-tool/
├── bin/            # CLI 入口
├── src/            # 核心逻辑
├── tests/          # 测试用例
├── .gitignore
└── package.json
```

## 开发

```bash
npm run dev
```
